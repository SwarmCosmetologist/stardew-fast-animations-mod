# Fast Animations

### Speed up Stardew Valley's time-consuming animations

Fast Animations accelerates the slow animations in Stardew Valley — eating, drinking, milking, shearing, fishing, and more. Get the same gameplay with less waiting, letting you do more in each in-game day.

<br>

---

## Features

| | |
|:---|:---|
| **Configurable Speed** | Set each animation type to your preferred speed multiplier independently |
| **Eating & Drinking** | Speed up the long consume animations that interrupt combat and farming |
| **Harvesting** | Faster tool swing and harvesting animations for marathon farming sessions |
| **SMAPI Compatible** | Works seamlessly alongside other popular SMAPI mods without conflicts |
